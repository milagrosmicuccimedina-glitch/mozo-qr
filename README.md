# Mozo QR

Landing de venta de **Mozo QR**: un QR en cada mesa para ver la carta online, llamar al mozo y pedir la cuenta.

Es una página estática (HTML + CSS + JS, sin dependencias), con una demo interactiva de una mesa y del panel del personal.

## Ver en la compu

```bash
python3 -m http.server 8000
```

y abrir http://localhost:8000

## Configurar

- **WhatsApp**: en `main.js`, completar `WHATSAPP` con el número (ej. `5492954123456`).

## Publicar

Se puede subir tal cual a Vercel, Netlify o GitHub Pages (no necesita build).
